# MIT courses on Bilibili

Top picks: **6.036** for machine learning, **6.S081** for operating systems,
and **6.824** for distributed systems. Here, systems engineering means
computer systems engineering.

| Course | Why take it | Bilibili version |
| --- | --- | --- |
| **6.036 — Introduction to Machine Learning** | Best starting point for ML foundations: perceptrons, regression, neural networks, trees, clustering, and reinforcement learning. | [2020 lectures — English + machine-translated Chinese subtitles](https://www.bilibili.com/video/BV1y44y187wN/) |
| **6.S191 — Introduction to Deep Learning** | A shorter introduction focused on neural networks: CNNs, sequence models, generative models, and reinforcement learning. Good after basic ML. | [2021 lectures — bilingual subtitles, 12 videos](https://www.bilibili.com/video/BV1jo4y1d7R6/) |
| **6.S081 — Operating System Engineering** | Hands-on systems foundations: virtual memory, system calls, concurrency, and file systems through the xv6 kernel. | [2020 subtitled upload](https://www.bilibili.com/video/BV19k4y1C7kA/) · [Chinese-dubbed alternative](https://www.bilibili.com/video/BV14h4oeAEvu/) |
| **6.824 — Distributed Systems** | Strongest recommendation for distributed systems: RPC, replication, Raft, GFS, ZooKeeper, transactions, and Spanner. | [2020 lectures — Chinese subtitles, 20 videos](https://www.bilibili.com/video/BV1iD4y1U7gu/) |
| **6.172 — Performance Engineering of Software Systems** | Learn why programs are slow and how to improve them: measurement, caches, compilers, parallelism, and synchronization. | [2018 lectures — English + machine-translated Chinese subtitles, 23 videos](https://www.bilibili.com/video/BV1wA411h7N7/) |
| **6.033 — Computer System Engineering** | Broader system-design principles. Treat the older recording as a supplement. | [2005 lectures — English subtitles](https://www.bilibili.com/video/BV197411s7AU/); playlist starts at lecture 4. |

## Suggested order

- **ML:** 6.036 → 6.S191.
- **Systems:** 6.S081 → 6.824; add 6.172 when performance interests you.
- Already comfortable with operating systems and concurrent programming?
  Start directly with **6.824**.

For the systems courses, make the programming labs central to your study:

- [6.S081 official schedule and xv6 labs](https://pdos.csail.mit.edu/6.S081/2020/schedule.html)
- [Distributed Systems official course site](https://pdos.csail.mit.edu/6.824/),
  now numbered **6.5840**. Use the past-year links for materials matching the
  2020 lectures.
